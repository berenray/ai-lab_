# AI Lab

Статичний сайт школи (HTML + CSS + трохи JS, без збірки). Три сторінки на спільній
дизайн-системі: головна з вибором курсу і дві посадочні під самі курси.

## Запуск

```bash
python3 -m http.server 4321
```

Далі http://localhost:4321

## Структура

```
index.html              — головна: вибір між двома курсами
automation/index.html   — курс з AI-автоматизацій (2 місяці)
claude/index.html       — курс по Claude (7 днів), збірка з окремого Astro-проєкту
anketa-mini/index.html  — анкета передзапису мінікурсу (окрема, без посилань з сайту)
workshop/index.html     — реєстрація на безкоштовний воркшоп 06.10 (кнопки ведуть у Telegram-бот)
legal/*.pdf             — договір оферта і політика конфіденційності
assets/css/tokens.css   — дизайн-система: primitive → semantic → component
assets/css/main.css     — layout і компоненти, спільні для всіх сторінок
assets/js/main.js       — FAQ, таймер, поява секцій
assets/img/*.webp       — 3D-обʼєкти та фото з презентації
```

Обидві посадочні побудовані за однією схемою: герой, картка довіри з цифрами,
болі на темному острові, «Для кого цей курс», бенто «На курсі ти», структура
курсу з 9 модулів, «Хто веде», бонуси, FAQ і фінальний блок. На `claude/` після
бонусів ще йдуть таймер і тарифи; `automation/` це ознайомчий лендінг без цін,
тарифів і таймера.

## Анкета мінікурсу

`anketa-mini/` це копія анкети `ai-expert.space/anketalm/evertg/` під нашим
доменом: ті самі питання, валідація і відправка. Сторінка навмисно стоїть
окремо від сайту — на неї немає посилань з головної, `automation/` і `claude/`,
у `<head>` прописано `noindex, nofollow`. Трафік ведемо прямим посиланням
`/anketa-mini/`.

Заявка одночасно йде в Google Sheets (аркуш `Мінікурс`) і в CRM через
Onlizer-вебхук, потім людину перекидає на `/anketa-mini/thanks/` з переходом у
Telegram-бот. Вебхук поки спільний з анкетами ЛМ, заявки відрізняються
заголовком «Заявки Мінікурс» і полем `page_source`. Усі адреси, ID пікселів і назва аркуша зібрані в
`anketa-mini/config.js`; код приймача для таблиці лежить у
`anketa-mini/backend/google-apps-script.gs`. Деталі — в `anketa-mini/README.md`.

## Дизайн-система

| Токен | Значення | Роль |
|---|---|---|
| `--bg` | `#F2F2F4` | холст |
| `--surface` | `#FFFFFF` | картки, радіус 24px |
| `--line` | `#E4E4E8` | межі карток |
| `--fg` | `#0F0F12` | текст і темні секції |
| `--accent` | `#FFD60A` | заливки: кнопки, маркер, чипи |
| `--accent-ink` | `#8A6D00` | акцент у тексті на світлому |

Шрифти: **Unbounded** 700/800 (заголовки, цифри) і **Golos Text** 400/500/600
(текст), обидва з Google Fonts.

Темні секції це не смуги на всю ширину, а «острови» зі скругленням 32px: клас
`.slab.theme-dark`. `.theme-dark` перевизначає той самий семантичний шар токенів,
тому всередині працюють ті самі компоненти (`.card`, `.btn`, `.plan`) без окремих
стилів. Два острови поспіль автоматично розсуваються, щоб між ними було видно
полотно.

## Що треба підключити або перевірити перед публікацією

- На `automation/` немає жодної кнопки дії, окрім «Дивитись програму». Якщо
  зʼявиться форма заявки або сторінка оплати, кнопку треба додати руками.
- Кнопки «Придбати курс» на `claude/` ведуть на `#`, постав посилання на оплату.
- Дедлайн таймера це атрибут `data-deadline` на `#timer` (формат
  `2026-08-12T23:59:59`). Підпис «до 12 серпня» поруч правиться руками. Таймер
  лишився тільки на `claude/`.
- Цифри в картці довіри (500+ студентів, 9.8 з 10, 4 роки в AI, 30+ виступів)
  взяті з ai-lab.com.ua, перевір актуальність.
- Додай `og:image` і аналітику.

## Правові документи

`legal/dogovir-oferta.pdf` і `legal/polityka-konfidentsiynosti.pdf`
(редакція від 09.09.2026). Посилання на них стоять у підвалі всіх трьох
сторінок і відкривають файл у новій вкладці.

Сторінка `claude/` це готова збірка стороннього Astro-проєкту, тому посилання
в її підвал вписані прямо в зібраний HTML і оформлені інлайновими стилями:
наш `assets/css/main.css` там не підключений. Після наступної пересборки того
проєкту їх треба буде додати знову, або одразу внести в його вихідний код.

Щоб оновити документи, досить покласти нові PDF під тими самими іменами.
