# Анкета мінікурсу

Копія анкети `ai-expert.space/anketalm/evertg/` під нашим доменом. Сторінка
самостійна: на неї немає жодного посилання з головної, `automation/` чи
`claude/`, у `<head>` стоїть `noindex, nofollow`. Потрапити можна тільки за
прямим посиланням, яке ти даєш у рекламі чи в боті.

```
/anketa-mini/          — сама анкета
/anketa-mini/thanks/   — сторінка подяки з переходом у Telegram
```

## Що відбувається після натискання «НАДІСЛАТИ АНКЕТУ»

1. Валідація: e-mail, Telegram-нік, усі 4 питання, телефон через
   `libphonenumber` + фільтр очевидно фейкових номерів.
2. `POST` у Google Apps Script → рядок в аркуші `Мінікурс`.
3. `POST` у CRM (Onlizer webhook) з полями форми, UTM, `eid` і `strimix_avid`.
4. `fbq('track', 'Lead')` з тим самим `eid`, щоб події не дублювались.
5. Редірект на `/anketa-mini/thanks/` з пробросом UTM.

## Налаштування

Усі зовнішні адреси лежать в одному файлі — `config.js`:

| Ключ | Що це |
|---|---|
| `sheetsEndpoint` | URL веб-застосунку Apps Script (`.../exec`) |
| `sheetName` | Назва аркуша, дублюється в hidden-полі `SheetName` в `index.html` |
| `crmWebhook`, `crmTitle`, `crmStage`, `crmSource` | Куди і під яким заголовком лягає лід у CRM. `crmWebhook: null` вимикає відправку |
| `thanksUrl` | Сторінка подяки |
| `telegramBotUrl` | Кнопка «перейти в канал» на сторінці подяки |
| `fbPixelId`, `clarityId`, `strimixId` | Аналітика; `null` вимикає трекер |

## Google Sheets

Код скрипта — `backend/google-apps-script.gs`, інструкція з розгортання в
шапці файлу. Коротко: Apps Script у потрібній таблиці → розгорнути як
веб-застосунок з доступом «Усі» → URL вставити в `config.js`.

Аркуш `Мінікурс` створюється сам при першій заявці, заголовки колонок
беруться з назв полів форми. Щоб бачити заявки у зведеній «LEADS AI LAB»,
додай там окрему вкладку з `IMPORTRANGE` на цей аркуш — так само, як зроблено
для інших джерел.

## Структура

```
index.html            — анкета
index.js              — валідація, відправка, редірект
config.js             — усі інтеграції
style.css             — стилі анкети (ті самі токени, що й на сайті)
loader.css            — оверлей-лоадер
js/                   — form-utils, phone-utils, utm-utils, loader, tracking
img/author.webp       — фото в герої (мобільна версія)
thanks/               — сторінка подяки (свої style.css, fonts/, img/)
backend/*.gs          — приймач для Google Sheets
```

Оригінал розводив заявки на 4 сторінки подяки (`thanks1`–`thanks4`), але вони
відрізнялись лише посиланням на бота. Тут одна сторінка; місце, де повернути
спліт, помічено коментарем у `index.js`.

## CRM

Поки що використовується той самий вебхук, що в анкет ЛМ, тому заявки
мінікурсу лягають у ту саму воронку: `stage 64`, `source 11`. Відрізнити їх
можна за заголовком **«Заявки Мінікурс»** і за полем `page_source`, у якому
стоїть `/anketa-mini/`.

Коли під мінікурс заведуть окрему стадію і джерело (або окремий сценарій в
Onlizer), досить поміняти `crmWebhook`, `crmStage`, `crmSource` у `config.js` —
код відправки не змінюється.
