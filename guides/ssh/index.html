Етап 1 · 3 хв

Створюємо ключ

SSH-ключ це пара файлів. Один лежить у тебе на комп'ютері, другий ти покладеш на сервер, і сервер пускатиме тебе без пароля.

1.1

Відкрий термінал на своєму комп'ютері

Термінал це вікно, куди вводять команди текстом. Він уже є на твоєму комп'ютері.

  1. Mac: натисни разом Cmd+Пробіл. Посередині екрана з'явиться пошук. Впиши Terminal і натисни Enter.
  2. Windows: натисни кнопку Пуск у лівому нижньому куті екрана. Впиши PowerShell і натисни Enter.
  3. Відкриється вікно з рядком, у кінці якого блимає курсор. Це і є термінал.
1.2

Створи ключ

  1. Натисни жовту кнопку Копіювати праворуч від команди нижче.
Команда для терміналу · Mac і Windows
ssh-keygen -t ed25519 -C "hermes"
  1. Клацни у вікно терміналу і встав команду: Cmd+V (на Windows Ctrl+V) (1).
  2. Натисни Enter.
  3. Термінал спитає «Enter file in which to save the key». Нічого не пиши, натисни Enter.
  4. Термінал спитає «Enter passphrase». Нічого не пиши, натисни Enter.
  5. Термінал спитає «Enter same passphrase again». Знову натисни Enter.
  6. Перевір, що з'явився рядок «Your public key has been saved» (2) і квадрат із символів. Ключ створено.
💡
Термінал спитав «Overwrite (y/n)?» Ключ у тебе вже є. Натисни n, потім Enter, і переходь до етапу 2.

Етап 2 · 3 хв

Передаємо ключ серверу

Кладемо твій ключ на сервер. Для цього востаннє вводимо root-пароль. Тримай під рукою IP-адресу сервера: вона в hPanel у рядку «SSH доступ», як у гайді «Файли агента у VS Code».

2.1

Підготуй команду зі своєю IP-адресою

У команді нижче замість IP_СЕРВЕРА мають стояти цифри твого сервера. Найпростіше підготувати команду в нотатках.

  1. Натисни Копіювати біля команди для своєї системи.
Команда для Mac
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@IP_СЕРВЕРА
Команда для Windows
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@IP_СЕРВЕРА "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys"
  1. Відкрий Нотатки на Mac або Блокнот на Windows і встав команду.
  2. Виділи мишкою слово IP_СЕРВЕРА і замість нього впиши IP-адресу свого сервера з hPanel.
  3. Перевір, що вийшло як у прикладі: root@, а за ним цифри без пробілу.
Приклад готової команди для Mac
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@123.45.67.89
2.2

Надішли ключ на сервер

  1. Скопіюй готову команду з нотаток.
  2. Клацни у вікно терміналу, встав команду і натисни Enter.
  3. Якщо термінал спитає «Are you sure you want to continue connecting (yes/no)?», впиши yes і натисни Enter.
  4. Термінал попросить пароль: «root@…'s password». Встав root-пароль і натисни Enter. Символів не видно, так і має бути.
  5. Mac: перевір, що з'явився рядок «Number of key(s) added: 1» (1). Ключ на сервері.
  6. Windows: після пароля термінал нічого не напише. Це нормально, переходь до етапу 3.

Етап 3 · 3 хв

Перевіряємо вхід

Підключаємося до сервера двічі: з терміналу і з VS Code. Обидва рази пароль питати не повинні.

3.1

Зайди на сервер з терміналу

  1. Скопіюй команду нижче і встав її в нотатки.
Команда для терміналу
ssh root@IP_СЕРВЕРА
  1. Заміни IP_СЕРВЕРА на свою IP-адресу, як на кроці 2.1. Вийде, наприклад, ssh root@123.45.67.89.
  2. Скопіюй готову команду, встав у термінал і натисни Enter (1).
  3. Перевір: пароль не питали, а останній рядок починається з root@ (2). Ти на сервері.
  4. Впиши exit і натисни Enter, щоб вийти із сервера.
3.2

Підключись через VS Code

  1. Відкрий VS Code.
  2. Натисни разом Cmd+Shift+P (на Windows Ctrl+Shift+P). Угорі з'явиться поле для команд.
  3. Впиши Remote-SSH: Connect to Host і клацни на цей пункт.
  4. У списку клацни на IP-адресу свого сервера.
  5. Перевір: поле для пароля не з'явилося, а в лівому нижньому куті є синя плашка SSH: з IP-адресою (1).

Де найчастіше спотикаються

Часті помилки і що робити

«Could not resolve hostname ip»

У команді залишилось слово IP (1). Встав команду ще раз із цифрами з hPanel.

«All keys were skipped because they already exist»

Ключ уже на сервері. Переходь до етапу 3.

Пароль усе одно питають

Повтори етап 2 і дочекайся рядка «Number of key(s) added: 1». Потім закрий вікно VS Code і підключись знову.

«Permission denied» на етапі 2

На сервері вимкнено вхід за паролем. Додай ключ через hPanel:

  1. Встав у термінал cat ~/.ssh/id_ed25519.pub на Mac або type $env:USERPROFILE\.ssh\id_ed25519.pub на Windows і натисни Enter.
  2. Термінал покаже рядок, що починається з ssh-ed25519. Виділи його повністю і скопіюй.
  3. У hPanel відкрий свій сервер. На сторінці «Огляд» натисни картку «SSH-ключ» → «Керувати» (1).
  4. Додай новий ключ і встав скопійований рядок.
Ноутбук загубився

Видали його ключ у hPanel: картка «SSH-ключ» → «Керувати». Потім постав новий root-пароль.
